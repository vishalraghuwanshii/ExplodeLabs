## 1. Executive Strategy: The Zero Domain Authority (DA 0) Playbook

As a newly launched domain with baseline Domain Authority (`DA 0` / `DR 0`), Explode Labs cannot immediately rank on Google page 1 for generic high-competition head keywords (e.g., *"video editing"* or *"web development"*, which have `KD > 90` and require thousands of referring domains).

Instead, Explode Labs utilizes a **3-Pronged Authority Bypass Strategy**:

```
                              ┌─────────────────────────────────────────────────────────────┐
                              │                 EXPLODE LABS DA 0 MOAT                       │
                              └──────────────────────────────┬──────────────────────────────┘
                                                             │
                    ┌────────────────────────────────────────┼────────────────────────────────────────┐
                    │                                        │                                        │
                    ▼                                        ▼                                        ▼
   ┌─────────────────────────────────┐      ┌─────────────────────────────────┐      ┌─────────────────────────────────┐
   │ 1. Low-KD Commercial Long-Tail  │      │ 2. Generative Engine Opt (GEO)  │      │ 3. Answer Engine Opt (AEO)      │
   │    • KD < 25 / "Easy"           │      │    • ChatGPT / Claude / Gemini  │      │    • Perplexity / SearchGPT     │
   │    • High-intent B2B modifiers  │      │    • Semantic Entity Triples    │      │    • 45-word Definition Boxes   │
   │    • Problem-solution queries   │      │    • Technical blueprints & code│      │    • Structured Data Tables     │
   └─────────────────────────────────┘      └─────────────────────────────────┘      └─────────────────────────────────┘
```

### The 3 Core Rules for DA 0 Domination:
1. **Never Target Pure Head Terms Alone:** Always anchor pages around **high-commercial-intent, low-KD modifier stacks** (e.g. `[Service] + [Industry/Framework] + [Agency/Services/Company]`).
2. **AI Citability Over Link Quantity:** AI search engines (Perplexity, SearchGPT, Claude, Gemini, Google AI Overviews) **do not require high domain authority to cite a website**. They cite pages that provide the most rigorous direct definitions, structured comparison tables, and unambiguous technical workflows.
3. **No Thin or Boilerplate Pages (Helpful Content Compliance):** Every flagship page must reach **1,800 to 2,500+ words** with unique engineering blueprints, comparison tables, tool evaluation decision trees, and 8+ deep technical FAQs.
